## How to add a memory

1. Decide whether it's project-specific (goes in `01 Projects/<repo>/02 Memories/`) or cross-project (goes here in `00 Notes/01 Memories/`).
2. Create a new file with a descriptive name: `<topic>.md`.
3. Start the file with `**Type:** feedback | reference | project` on the second line.
4. Include **Why** and **How to apply** sections so future readers (including future you) understand when this memory matters.
5. Add a row to this table linking the new file.

## Memory types

- **feedback** — how to behave (preferences, corrections, confirmed approaches)
- **reference** — where to find things (file paths, dashboards, external systems)
- **project** — facts about ongoing work (active decisions, constraints, deadlines)
